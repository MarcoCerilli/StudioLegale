# Studio Legale Avvocato Anna Fusco

Sito web istituzionale dello **Studio Legale Fusco** (Terracina, LT).
Sviluppato con **Astro 5**, **Tailwind CSS v4** e ottimizzato per massime performance (100/100 Core Web Vitals), accessibilità (WCAG 2.1) e SEO locale per il settore legale.

## 🚀 Caratteristiche Tecniche

- **Framework**: [Astro](https://astro.build) (Zero JS per default sui contenuti statici)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) con tema personalizzato istituzionale
- **Icone**: [lucide-astro](https://github.com/lucide-icons/lucide)
- **SEO & Structured Data**: Schema.org `LegalService`, OpenGraph, Twitter Cards, Sitemap XML automatica (`@astrojs/sitemap`), `robots.txt`
- **Accessibilità (a11y)**: Gerarchia titoli conforme (`h1` -> `h2` -> `h3`), target minimi touch 44x44px, contrasto elevato, navigazione da tastiera e supporto screen reader
- **Interattività**: Widget di consulenza rapida con apertura guidata da ogni CTA del sito e fallback WhatsApp diretto

## 🛠️ Comandi di Sviluppo

```sh
# Installa dipendenze
npm install

# Avvia dev server locale
npm run dev

# Compila build di produzione
npm run build

# Anteprima della build
npm run preview
```
